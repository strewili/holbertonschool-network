# Networking basics #0

## المفاهيم

**نموذج OSI** — إطار نظري يصف الاتصال في الشبكات على 7 طبقات، من الطبقة 1
(الفيزيائية: إشارات كهربائية أو ضوء أو راديو) إلى الطبقة 7 (التطبيقات مثل HTTP).
هو مجرد تصوّر ذهني ليساعدنا نفهم، ما ينفّذ شي بنفسه.

**أنواع الشبكات**

| النوع | الاستخدام | الحجم الجغرافي |
| --- | --- | --- |
| LAN | يربط الأجهزة المحلية (بيت، مكتب، مدرسة) | مبنى واحد أو بضعة مباني |
| WAN | يربط عدة شبكات LAN مع بعض | مدينة أو دولة |
| Internet | أكبر WAN في العالم — شبكة الشبكات | عالمي |

**MAC vs IP**

| | MAC address | IP address |
| --- | --- | --- |
| وش هو | المعرّف الفريد لواجهة الشبكة (كرت الشبكة) | عنوان الجهاز على الشبكة |
| التشبيه | الرقم التسلسلي للكرت | العنوان البريدي للبيت |
| يتغيّر؟ | ثابت مع الجهاز | يتغيّر حسب الشبكة |

نوعا الـ IP: **خاص (private)** داخل الشبكة المحلية، و**عام (public)** على الإنترنت.
و `localhost` = `127.0.0.1` = الجهاز نفسه.

**TCP vs UDP**

| | TCP | UDP |
| --- | --- | --- |
| السرعة | أبطأ | أسرع |
| الموثوقية | يتأكد من وصول كل شيء ويعيد الإرسال | قد يفقد بيانات |
| الاستخدام | تصفّح، تحميل ملفات، بريد | بث مباشر، ألعاب، مكالمات |

**المنافذ (Ports)** — لكل جهاز 65535 منفذ. التشبيه: لو الـ IP هو عنوان البيت،
المنافذ هي الأبواب والنوافذ. وأشهرها: **22** للـ SSH، **80** للـ HTTP، **443** للـ HTTPS.
و `IP + port` يسمّى **socket**.

**ICMP / ping** — بروتوكول تستخدمه الأجهزة للتأكد أن جهازاً آخر متاح على الشبكة.
